# RA APP

Projeto Web + PWA responsivo para portfólio e divulgação de serviços.

## Rodar
npm install
npm run dev

## Build
npm run build

## Configuração
Edite `src/main.jsx` e altere `WA` para seu WhatsApp. Antes de produção, substitua os placeholders das políticas por dados oficiais.

## Android
Para transformar o build web em app Android, pode-se adicionar Capacitor posteriormente. Gere primeiro o build de produção.

## Importante
As páginas jurídicas são modelos e devem ser adaptadas aos dados reais e revisadas por profissional jurídico antes do uso comercial.

Sem Docker.
